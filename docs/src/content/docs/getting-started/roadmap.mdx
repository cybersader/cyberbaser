Cyberbaser is an **interoperability layer for contributable, version-controlled knowledge bases**. The contributable-wiki capability is what that layer enables: the current build uses Obsidian (and other markdown surfaces) as a first-class authoring surface, a Git-backed vault as today's source of truth, and zero-git contribution for anyone. The roadmap reflects this: research and architecture come first, features are built on that foundation, and every significant decision is [logged with rationale](/cyberbaser/agent-context/zz-log/).

See the [vault vision mining](/cyberbaser/agent-context/zz-log/2026-04-13-vault-vision-mining/) for the original dream, and the [vault tech stack mining](/cyberbaser/agent-context/zz-log/2026-04-13-vault-tech-stack-mining/) for the 300+ curated links that seed the research below.

:::note[How this roadmap is maintained]
This page is the **living roadmap** — only active and future phases live here. Every significant decision gets a dated entry in the [decision log](/cyberbaser/agent-context/zz-log/). Link roadmap items to their log entries so the *why* is always reachable from the *what*.
:::

## Current phase: v1 Build (foundations closed 2026-07-25)

**If you're returning after a long gap, the arc so far in five sentences.** The research phase settled the identity (an interoperability layer, not a publishing tool), proved a masking layer that protects Obsidian syntax through a markdown parser, and wrote the foundations. An adversarial pass then [audited the plan itself](/cyberbaser/research/plan-critique/) and produced [three competing designs for what v1 is](/cyberbaser/research/v1-build-plan/). Rather than argue, we ran the deciding measurement: the round-trip pipeline against **all 1430 real vault files**, which returned 4.6% byte-identity and proved that *whole-file re-serialization can never preserve real files* — so no such step is allowed in any write path, ever. That locked the v1 shape ([R12](/cyberbaser/research/v1-build-plan/#gate-result-run-2026-07-25)): **byte-preservation by construction** (edits are raw-text splices), **validation as the product** (a detector for tools that corrupt markdown), and governance on top. The first artifact, the [`@cyberbaser/ofm` validator](https://github.com/cybersader/cyberbaser/tree/main/packages/ofm), is built and tested.

### Building now

- [x] **`@cyberbaser/ofm` v0.1** — the validator: masking core, change classifier (`clean | suspect | damage`), corpus reporter, CLI. Built + 10 tests green + smoke-tested on the real vault (2026-07-25).
- [ ] **CI gate on the vault repo** — `ofm-check diff` on every markdown-touching PR, report-only first, then required. This makes [Principle 2](/cyberbaser/getting-started/principles/) enforced instead of aspirational.
- [x] **The publish boundary, selector half** — `@cyberbaser/publish` v0.1 (2026-07-25): the default-deny selector, slug contract, and safety lint, 91 tests green. Remaining: the maintainer authors the real `publish.yml`, plus projection wiring.
- [x] **Renderer decided by measurement** — Quartz adopted for the vault site (R14, 2026-07-25): the real vault builds in 1:55 and scores 20/20 on the OFM checklist; the path census killed the mass-rename question (0 collisions, 2 violations). [Results + the fine print](/cyberbaser/research/quartz-spike-results/). Remaining: projection wiring, pre-publish fixes, the v4-vs-v5 pick.
- [ ] **Edit path, when triggered** — the raw CM6 widget ships when a real non-git contributor is blocked or mobile dogfood friction recurs; until then "edit on GitHub" is the web path. The [suggestion unit](/cyberbaser/research/option-space/) (CriticMarkup + reject-all invariance) is the candidate beyond that.

**Exit criteria for v1 Build:**

- [x] The vault renders and publishes through the publish boundary with leak tests green — **live 2026-07-25: [cybersader.github.io/cyberbase](https://cybersader.github.io/cyberbase/)** (R16: 933 pages + 373 assets, verbatim-path v0, deploy 16 s)
- [ ] The round-trip CI gate is a required check on the vault repo (report-only window running; its first rehearsal caught a masked crash on emoji paths, fixed — see R17)
- [ ] The maintainer makes a real web edit that lands as a clean splice-only commit — **machinery proven 2026-07-25/26**: two rehearsal edits ran the full circuit (queue → `ofm-check: clean` → merge → auto-redeploy → verified live), and every page now carries an "Edit this page" link. The criterion closes on the maintainer's own first click.
- [ ] URL contract frozen with the slug-diff gate on
