## Owner correction

The owner said, **“better but showing the criticmarkup AND this dropdown doesnt make sense”**. Their screenshot showed struck **sixty**, underlined **forty**, and an expanded **Previous** repeating the whole old paragraph below it. ## Narrow implementation

Other row kinds retain their existing disclosure behavior, including block, source-only and unsupported fallbacks. Global Details still contains the pinned version, comparison, full pinned/proposed exact source and authoritative operation. The change is one rendering condition, not a differ or fidelity-policy change.

Directly affected assertions now require inline old/new marks with no local Previous, literal notation unchanged, fallback Previous retained, and global evidence reachable. The existing real-preparation variation test covers the inline and source/table cases. Its gated browser body required no adaptation and remains unchanged. Client, CSS, toolbar, modal logic, Publish/confirmation/payloads, authentication, backend authority, source bytes and diff/projection core are unchanged.
