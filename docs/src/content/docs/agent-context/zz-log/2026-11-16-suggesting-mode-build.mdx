## Decision

The maintainer approved the [suggesting-mode direction](/cyberbaser/research/wysiwyg-suggesting-mode/) and asked to use mainly Astra and Sol workers. Recorded in `.claude/41-QUESTIONS-RESOLVED.md` ("Suggesting mode direction selected").

The first resumed provenance attempt stopped correctly at a boundary: Quartz trims input before any plugin hook. The coordinator authorized a minimal, hash-verified patch rather than a parallel parser. Intake and owner workers were briefly blocked on the missing shared trust export, which the coordinator added.

## Integration findings

- Owner-alpha now passes `CYBERBASER_SOURCE_PROVENANCE=enabled` whenever the suggestion form is on. The hands-on rehearsal had its own copy of the build inputs and silently omitted it; it now reuses the owner renderer's `suggestionEnvironment`. Its real-Quartz tests did not detect the gap and should gain a provenance assertion.
- On a real page (Awesome Stream Deck Alternatives) suggesting mode mapped 172 runs and tracked two edits, but sending was refused with a false "Rendered text changed" stale-page error. Root cause: the coordinator's Playwright screenshot hid the caret and left `style=""` on a deletion mark; the safety check compared serialized markup and refused. The check now ignores only empty style attributes on a detached snapshot, keeping text, tags, nonempty attributes and locators strict, with a screenshot regression test. After rebuilding, the real page sent both edits as one v2 suggestion and returned a receipt, with marks cleared and no page errors. A real reader is unlikely to hit the original case, but extensions can make the same harmless change.
- The page renders `$2.99/Monthly | $24.99` as inline math: Quartz treats paired dollar signs as LaTeX. Pre-existing, separate from suggesting mode.
