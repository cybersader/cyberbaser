title: Renderer workspaces and upgrade gate
---

A renderer's writable working files are disposable. Source-checkout dependency bootstrap uses a fresh directory that is never an isolated build's write root. Installed and configured renderer trees stay outside that grant. The node refuses overlapping job-store, site and cache trees before building, and native upgrades probe the staged launcher before stopping the previous services.

Native assembled Quartz built from a disposable copy, emitted private provenance, and left the installed patch targets unchanged. The restricted runtime uses Bun and exact diff application without chmod or xattr operations; the renderer filter was not loosened. Targeted tests: 171 passed, three skipped, zero failed (1,648 assertions). The local kernel reported Landlock ABI 9. The launcher reaped 24 exited fixture helpers while their leader remained alive, and passed the separate detached-child timeout check.

The exact `1dee514` Linux/amd64 release passed the rootful Docker 29.7.2 default-seccomp rehearsal with a disposable private vault and no external relay. It passed private setup and replay refusal, enrollment custody, config reconciliation and exactly one automatic publisher restart on a checked change, unsigned pending-job recovery, one signed fixture push, and authenticated reads. The detached child was gone before the reader served the manifest-bound asset. Both stock and assembled Quartz served the new revision, and the assembled renderer's installed patch targets stayed unchanged. The packaged launcher reported ABI 9, passed the separate no-network preflight with container init enabled, and reaped all 24 helper exits before the leader exited.

The maximum sampled role peaks were 1,327,652,864 bytes for the node, 47,071,232 for the publisher and 27,627,520 for the reconciler. No sampled OOM counters or lab OOM events were seen. Lab resources were removed and the release image retained. The appliance's effective Landlock, Docker and AppArmor profile, the native systemd upgrade, and any real publishing remain untested and separately gated.
