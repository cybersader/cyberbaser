## Bounded implementation

The adapter and adjacent deterministic tests remain private and ignored. The adapter accepts an explicit source/address binding and one trusted local read callback. It constructs one exact request, treats the returned data as untrusted and consumes only the structured result. The optional human-readable copy is not parsed or used as authority.

Binding values are snapshotted before use. An invalid mapping causes no callback call; each valid request causes exactly one. Response identity is checked against the frozen binding, not a mutable request object handed to the callback. Unknown fields, accessor-based data, mismatched addresses, invalid versions, truncation and inconsistent lengths refuse. A successful result emits only the existing strict capture fields, with UTF-8 bytes and digest computed from the returned text. Private connector settings do not become mapping, reference or publication-artifact fields.

Text is not trimmed, repaired or normalized. Multibyte and decomposed Unicode, absent final newlines, literal valid replacement characters and leading byte-order marks retain their returned representation. Ill-formed Unicode refuses. The private adapter refuses CR-containing text rather than converting it. Existing preparation independently refuses a leading byte-order mark. **The CR rule belongs to this adapter; core-wide CR behavior through other readers remains unverified.** This is a future integration qualification, not a verified core defect.

Refusals expose only fixed safe diagnostic values. A validated finite retry hint can remain inert data; there is no sleep, retry, fallback read, transport or credential implementation. Strict unknown-field rejection deliberately fails closed, even for a benign upstream schema addition. Deployed compatibility must be verified rather than assumed.

## What the evidence does not establish

The demonstrated property is **returned-text self-consistency**. It does not prove original raw-disk byte fidelity, preservation through a live upstream character-decoding path, authoritative positive version semantics, or coherence while another process edits the source. A matching digest cannot establish those guarantees by itself.

The ignored private tests are **not CI gates**. Successful conformance must be rerun against then-current core immediately before any future activation. An implementation-pinned synthetic shape is not a stable public contract or evidence that a deployed endpoint matches it.

Normal startup still has no connected authoring reader. The owner application's root redirect reaches its own panel; it is **not an external authoring-workspace entry point**. No transport, public provider API, loader, runtime delivery mechanism or new product decision was selected here.

## Remaining connection gates

1. **Authorized transport and binding verification.** Obtain and verify an exact binding through separately authorized access. Do not infer or populate a real binding from synthetic evidence. Verify the deployed success and refusal envelopes, including strict unknown-field compatibility.
2. **Upstream integrity guarantees.** Establish character preservation, authoritative version semantics and coherent capture under concurrent editing. Keep original disk-byte fidelity distinct from returned-text consistency.
3. **Actual live source-byte cap.** Future wiring must pass the actual configured source limit to the adapter. Synthetic configuration and core validation do not prove this connection has been made.
4. **Selected page and fresh baseline.** Map one existing public page to a freshly reconciled authoritative publishing baseline before enabling a writer.
5. **Runtime delivery and normal entry.** Resolve delivery into the runtime mirror, startup wiring and navigation from the normal authoring workspace. The existing root redirect does not satisfy this gate.
6. **Separate activation and publication authority.** Real activation and a first publication remain separately authorized through the existing owner-controlled route. No page was selected, enrolled or published in this slice.
