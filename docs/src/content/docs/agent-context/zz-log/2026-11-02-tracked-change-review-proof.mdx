## Bounded implementation and deterministic proof

The publication-only helper compares the existing source-replay-verified base/candidate block projections, anchors source-equal blocks with bounded LCS, pairs compatible changed positions and compares full token identity. Plain-text replacements may refine at grapheme-validated word boundaries; formatted/link/code changes remain whole tokens. Dropping removed runs must reconstruct the complete candidate token stream, and dropping added runs the complete base stream, including actual token metadata. Structural metadata is checked separately. These are lossy **projection endpoint** guarantees, not precise byte-span mapping, byte rendering or unique authoring history. Source application remains governed by the unchanged exact-operation replay and owner route.

The same full Shared workshop handbook renders literal underlined additions and struck deletions where reconstruction passes. Clean reading changes presentation only; navigation restores hidden changes before focus and announces that changes are shown. Source-only differences, including discarded code-language/list-number details, retain explicit source/formatting marks and previous/source evidence. Unsupported syntax, incompatible structures, changed-region disagreement and exceeded budgets receive labelled block/exact/coarse fallbacks. At this initial proof stage, broad rewrites could open clean with class counts and Show changes, without promising inline detail for fallback blocks. The later quiet refinement removes those category tallies. No per-change resolution, invented author identity, parser, canonical notation storage, import/export or fork was added.

Display-only bounds are 2,000,000 block-LCS cells, 20,000 token-LCS cells per group, 40,000 word-LCS cells per replacement, 400 eligible blocks, 2,000 inline marks and 2,000,000 cumulative cells. Preparation policy and publication authority are unchanged.
