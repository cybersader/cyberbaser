## Request

The maintainer asked to prepare something to test hands-on soon. They also hoped the agentic-workflow agent applies the protocol-driven controls principle; the principle was sent to that thread with a request to place it under its own knowledge-curation rules.

## Work

Two Sol workers ran in parallel with disjoint ownership and a frozen owner-config contract.

- **Owner app bot check:** optional `suggestions.form.challenge` (`provider`, `siteKey`, `secretFile`, `expectedHostnames`) participates in policy identity and site-cache invalidation, derives the intake's `botCheck`, passes only provider and public site key to the renderer, and widens the reader CSP using the provider registry's `scriptOrigin`, so owner-alpha contains no vendor strings. The Turnstile provider accepts Cloudflare's test-response shape (hostname `example.com`, no action) only for the three exact published test secrets; real secrets keep strict checks. Two owner test fixtures that submit corpus-sized batches declared larger limits; product defaults are unchanged.
- **Launcher:** `bun run --cwd docs try:suggestions` builds a throwaway Git vault with three short notes, a local bare remote and a private owner workspace on loopback, prints sign-in, page and Proposals links plus six steps, and removes its state on stop. `--prepare` installs the pinned app dependencies and Quartz seed once; `--challenge pass|fail|spent` uses Cloudflare's published test keys. Guide: [Try suggestions on a throwaway vault](/cyberbaser/development/try-suggestions/).
