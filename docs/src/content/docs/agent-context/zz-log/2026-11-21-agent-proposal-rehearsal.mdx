The [agent proposal rehearsal](/cyberbaser/development/agent-proposal-rehearsal/) makes the existing signed proposal path usable with a disposable workspace capture and vault. The agent child signs a bounded exact change against the published commit's Git blob. The same owner inbox displays its enrolled agent label. Approval records a decision; the separate Apply act can start an ordinary Save job. Nothing in enrollment or the carrier grants the agent either owner act.

The new opt-in node settings load a private public-key registry and expose only signed proposal submission over a private Unix socket. Registry contents do not enter publication policy. The client reuses the workspace line-ending/BOM spelling and contiguous byte splice logic. An unchanged folded note submits nothing; changing properties still yields a proposal but not permission to apply.

The rehearsal shares the existing isolated sign-in and disposable suggestions runtime, including the real intake writer and retained publication binding. Build, deployment, live confirmation and rebuild are synthetic. The automated owner-path test recorded separate approval and application, then verified the actual disposable note, checkout commit and local bare remote. A separate run verified authenticated inbox visibility and owned cleanup without opening Chromium. This is mechanical local evidence, not a real-vault run or human acceptance.
