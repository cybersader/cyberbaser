Design is downstream of [Concepts](/cyberbaser/concepts/) and [Principles](/cyberbaser/getting-started/principles/). The current v1 product interpretation is an **owner-controlled change boundary** around a version-controlled knowledge base. Authoring and rendering tools are replaceable spokes. Every external authoring adapter must preserve owner authority, emit bounded proposals against pinned source, leave untouched bytes identical, and avoid becoming a second content authority.
