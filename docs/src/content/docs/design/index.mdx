Design is downstream of [Concepts](/cyberbaser/concepts/) and [Principles](/cyberbaser/getting-started/principles/). The current v1 product interpretation is an **owner-controlled change boundary** around a version-controlled knowledge base. Every design must preserve owner authority, untouched source bytes, and the ability to swap today's GitHub and Quartz dogfood infrastructure.
